# 📝 Notely — Full-Stack Notes Website

> A modern and secure full-stack notes management platform built to help users create, organize, search, and manage their personal notes efficiently.

---

## 🚀 About The Project

**Notely** is a full-stack web application that provides users with a simple and intuitive platform to manage their personal notes.

The project includes a React-based frontend, a Node.js/Express backend, MongoDB database integration, and JWT-based authentication for secure user access.

---

## ✨ Features

- 🔐 User Registration & Login
- 🛡️ JWT-Based Authentication
- 🔒 Protected API Routes
- ➕ Create New Notes
- ✏️ Edit Existing Notes
- 🗑️ Delete Notes
- 📌 Pin & Unpin Notes
- 🔍 Search Notes
- 🏷️ Filter Notes by Tags
- 🌙 Dark Mode
- ☀️ Light Mode
- 📱 Responsive User Interface
